# W4Studica

W4Studica는 Studica VMX-pi에서 2027 WPILib으로 로봇을 개발하고 실행할 수 있도록 만드는 커뮤니티 프로젝트입니다. 현재 베타 버전을 개발하고 있습니다.

## 왜 만들었나요?

Studica의 WPILib 2020 지원이 끝나면서, VMX-pi에서 예전 환경에 계속 머무르지 않고 새 WPILib을 사용할 방법이 필요했습니다.

하드웨어 드라이버를 전부 새로 만드는 대신, Studica가 ROS 2에서 사용하는 드라이버 코드를 바탕으로 VMX-pi의 장치를 연결합니다.
같은 드라이버 코드를 활용하면 비슷한 기능을 따로따로 만들 필요가 줄고, Studica 장치 지원도 한곳을 중심으로 관리하기 쉽습니다.
W4Studica는 이 드라이버와 WPILib을 연결해 VMX-pi에서도 익숙한 로봇 개발 흐름을 이어가도록 만들고 있습니다.

## 어떻게 사용하나요?

PC에서 C++ 로봇 코드를 작성하고 빌드한 뒤, GradleRIO로 VMX-pi에 배포합니다.
VMX-pi에서는 WPILib과 하드웨어 드라이버를 이어주는 W4Studica 확장을 사용해 프로그램을 실행합니다.

디지털 입출력, 아날로그 입력, 엔코더는 WPILib 방식으로 사용할 수 있습니다.
Titan 같은 Studica 장치의 고유 기능은 Studica API와 W4Studica의 도우미 클래스로 사용합니다.

## 현재 진행 상황

현재 **2027.0.0-alpha-7 기반 베타 버전**을 개발하고 있습니다.
C++ 로봇 프로그램의 빌드와 배포, 디지털 입출력·아날로그 입력·엔코더·Titan 제어를 실제 VMX-pi에서 확인했습니다.
IMU는 일부 동작을 더 확인해야 합니다. PWM·DutyCycle·I2C의 WPILib 하드웨어 지원은 아직 제공하지 않습니다.

지원 범위를 넓히면서 기능별 확인 결과와 사용 방법을 문서에 정리하고 있습니다.

W4Studica는 Studica 또는 WPILib의 공식 배포판이 아닌 커뮤니티 프로젝트입니다.
